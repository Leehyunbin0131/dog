# Assembly manual source availability

The complete delivered Korean PDF is in `assembly/Micro_Dog_X430_Assembly_Manual_KO.pdf`. Its original PDF-generation scripts and some standalone illustration source files were not recoverable after the build workspace restarted, so manual regeneration is not supported by this release. This omission does not affect the complete PDF, final STL/STEP/FreeCAD assets, BOM, or the independently generated and tested URDF package.

Available selected CAD renders remain in `../images/assembly/`; they are supplemental references, not a complete regeneratable manual source set. Native CAD is available for future documentation updates.
