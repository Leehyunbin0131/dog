# Micro_Dog X430: 그림 매뉴얼용 조립 순서와 체결 방향


## 문서 범위와 기준
- 중앙 몸체 제외 네 다리. 본문은 RR 한 다리를 완성하는 순서이고, 각 단계의 수량은 **한 다리 기준**이다. 전체 수량은 마지막 집계에서 ×4한다.
- 각 모터의 출력 혼과 혼 중심 고정나사는 이미 정상 설치된 상태로 시작한다. 그 중심 나사는 아래 144개에 포함되지 않는다. 매뉴얼에서 출력 혼을 분리하도록 지시하지 않는다.
- 전원은 끈다. 케이블 연결과 경로를 먼저 확보한다. 조립 그림의 정적 자세를 전기적인 영점 각도라고 부르지 않는다. 모터 기준 위치와 혼 표시를 확인하되 검증되지 않은 ID/각도/토크 값을 만들지 않는다.
- 조립도에 쓰는 ‘안쪽/바깥쪽’은 부품명과 머리/너트 자리로 함께 표시한다. 화면의 왼쪽/오른쪽만으로 방향을 지시하지 않는다.
- 아래 L_X는 RR 다리 Part 내부 좌표다. 골반 H_X는 별도 좌표다. 이 두 축을 하나로 혼동하지 않는다. LH에는 RR 좌표값을 그대로 적용하지 말고 해당 부품의 머리 포켓·너트 포켓을 따른다.
- 아래 순서는 드라이버와 너트 접근을 확보하려는 조립 계획이다. 전체 드라이버 삽입 동작을 물리 시험했다는 뜻은 아니다.

## 01. 부품 분류와 시험 끼움
그림: 한 다리 부품 트레이, 세 모터를 용도별로 구분.
- XM430 1개 = 롤; XL430 2개 = 피치/무릎.
- XL 키 스페이서4개, XM 케이스 스페이서4개. 두 종류를 섞지 않는다.
- 큰 베어링7×13×4 두 개(다리 관절용1 + 롤용1), 작은 베어링6×10×2.5 두 개.
- 대퇴1, 안쪽 종아리1, 종아리 반대판1, 크랭크1, 푸시로드1, 큰 캡1, 작은 캡2, TPU발1, 롤 캐리어2, 요크1, 고정 지지대1.
- 너트와 머리가 포켓에 손으로 안착하는지 먼저 확인한다. M3 머리 Ø5.5/너트 AF5.5, M2.5 너트 AF5 포켓은 명목 끼움 여유0이다. 나사 조임으로 억지 압입하지 않는다.
사용 나사: 없음.

## 02. 가려지기 전에 너트 넣기
그림: 포켓별 확대와 너트 아이콘. 이 단계에서 너트를 넣고 나중 단계에서 다시 ‘추가’로 세지 않는다.
- 안쪽 종아리의 중간 두 곳 + 발끝 한 곳: M3 너트3개. 바깥쪽 깊은 육각 포켓에 넣는다. RR L_X=30.9375 쪽에서 안으로, 받침면34.9375에 닿게 한다.
- 종아리 반대판의 큰 관절 자리: M3 너트1개. 큰 캡이 들어가는 면의 반대쪽 육각 포켓에 넣는다. RR 받침면 L_X=51.8125, 너트는 +L_X 쪽.
- 작은 캡 두 개: M3 너트 각1개. 캡의 넓은 바깥쪽 육각 포켓에 넣는다. 축이 돌출된 면의 반대쪽이다.
- 요크 끝 고정 지지대 연결부: M2.5 너트2개. 측면 슬롯(+H_Y 쪽 입구)에서 넣어 두 구멍 중심에 맞춘다. RR 받침 H_X=52.5, 너트는49.5..52.5 포켓 안쪽에 놓인다.
합계: M3 너트6개 + M2.5 너트2개. 아직 나사 없음. 탈락하지 않게 받치고, 포켓에 맞지 않는 너트를 접착제로 숨겨 고정하지 않는다.

## 03. 푸시로드에 작은 베어링 두 개
그림: 푸시로드의 양 끝 구멍과 실제 폭2.5 치수.
- 6×10×2.5 베어링2개를 푸시로드 양 끝의 Ø10 자리에 넣는다.
- 하우징에 넣을 때 외륜을 지지한다. 안쪽 링을 눌러 외륜을 강제로 압입하지 않는다.
- 해당 규격의 양면 대칭 베어링은 표시 면 방향을 특정할 필요가 없다. 폭3 베어링으로 대체하지 않는다.
사용 나사: 없음.

## 04. 크랭크–푸시로드 작은 관절 먼저 완성
그림: 크랭크 모터면 → 나사 방향 화살표 → 작은 반축 → 푸시로드/베어링 → 작은 캡/너트.
- 크랭크 작은 반축을 푸시로드 한쪽 베어링 내경에 넣고 반대쪽에서 작은 캡의 반축을 맞춘다.
- M3×12 원통머리1개를 **크랭크의 모터를 향하는 뒤쪽 머리 포켓에서 작은 캡 쪽으로** 넣는다. 캡에 미리 넣은 M3 너트1개에 체결한다. 와셔 없음.
- RR +L_X 방향. 머리 받침49.5, 너트 받침57.3125. 나사머리는 크랭크 쪽, 너트는 작은 캡 바깥쪽.
- 이 작업을 크랭크를 무릎 모터 혼에 붙이기 전에 한다. 모터가 붙으면 나사머리 쪽 드라이버 접근이 막힐 수 있다.
- 푸시로드가 부드럽게 회전하는지 확인한다. 과하게 조여 베어링 외륜/푸시로드를 움직이지 못하게 누르지 않는다.
사용: M3×12 1개, 이미 배치한 작은 캡 너트1개.

## 05. 푸시로드–종아리 반대판 작은 관절
그림: 반대판의 안쪽 머리 포켓 → 푸시로드/베어링 → 작은 캡.
- 반대판의 작은 반축에 푸시로드의 남은 베어링을 넣고 바깥에서 작은 캡을 맞춘다.
- M3×14 원통머리1개를 **반대판의 안쪽 머리 포켓에서 작은 캡 쪽으로** 넣는다. 캡 너트1개에 체결한다. 와셔 없음.
- RR +L_X 방향. 머리 받침47.8125, 너트 받침57.1875.
- M3×12와 바꾸지 않는다. 두 작은 관절은 잡는 두께가 달라 길이가 다르다.
사용: M3×14 1개, 이미 배치한 작은 캡 너트1개.

## 06. 먼저 빈 대퇴를 피치 혼에 연결
그림: 대퇴의 피치 연결4구멍과 모터 혼의 나사4구멍 확대.
- 무릎 모터가 아직 없는 빈 대퇴를 피치 XL 출력 혼에 맞춘다. 롤 캐리어도 아직 장착하지 않는다.
- M2×8 원통머리4개를 **대퇴 바깥 머리 받침면 → 피치 XL 혼** 방향으로 넣는다. 너트/와셔 없음.
- RR -L_X, 머리 받침9 → 혼면3. 크랭크와 마찬가지로 네 M2 나사구멍만 사용한다.
- 반드시 무릎 모터를 붙이기 전에 이 네 나사를 조인다. 저장 자세에서는 무릎 모터와 나사머리 사이가 약1 mm뿐이라 드라이버를 곧게 넣을 수 없다.
사용: M2×8 4개.

## 07. 케이블 먼저, 무릎 XL과 대퇴 결합
그림: 무릎 모터 옆창/대퇴 뒤쪽 케이블 홈, XL 스페이서4곳, 접시머리 삽입 방향.
- 피치 XL과 대퇴만 먼저 연결된 상태로 진행한다. 크랭크·푸시로드·종아리의 닫힌 링크와 롤 캐리어는 아직 결합하지 않는다.
- 무릎 케이블을 지정 통로에 먼저 통과시키고 커넥터에 연결한다. 이후 틈에 커넥터를 억지로 통과시키지 않는다.
- 무릎 XL 뒤쪽 네 파인 자리에 XL 키 스페이서4개를 놓고 대퇴 장착판과 맞춘다.
- M2.5×20 낮은90°접시머리4개를 **대퇴의 접시머리 포켓에서 XL 뒤쪽 케이스 쪽으로** 넣는다. 너트/와셔 없음. 해당 모터의 기존 네 코너 나사를 교체하는 체결이다. 원래 나사 위에 나사를 겹쳐 넣지 않는다.
- **아래쪽 두 나사는 임시 회전 접근이 필요하다.** 저장된 자세의 아래 두 나사(Y=±11,Z=-93.5) 앞은 피치 케이스가 막는다. 대퇴와 무릎 모터를 받친 상태에서 전원이 꺼진 피치 모터 케이스를 출력축 둘레로 천천히 돌려, 조일 나사의 드라이버 직선 경로가 케이스 바깥으로 나오게 한다. 두 나사를 각각 노출시키며 체결한다. 케이블이 당기거나 비틀리지 않게 한다.
- 참고상 각 아래 나사축을 피치 케이스의 짧은 측면 밖으로 옮기면 축–케이스 경계가 명목2.35 mm 남는다. 지름3 mm 이하의 곧은 드라이버 축을 가정하면 여유0.85 mm이다. 실제 드라이버 손잡이와 삽입 동작까지 검증된 것은 아니므로 이 단계는 본 조립 전에 실물로 시험한다. 케이스를 돌리는 도중의 간섭과 실제 모터의 수동 회전도 아직 검증되지 않았다. 접근이 되지 않으면 억지로 비스듬히 돌리지 말고 조립을 멈춰 접근 방법을 재검토한다.
- 위쪽 두 나사(Z=-53.5)는 저장 자세에서 피치 케이스가 직선 경로를 막지 않는다. 모든 나사를 마친 뒤 피치 케이스 방향을 해당 모서리의 조립 기준 방향으로 돌려놓는다. 임시 조립 회전을 전기 영점 변경으로 설명하지 않는다.
- 머리 외경4.7 이하 DIN965/ISO7046-2. 큰 육각렌치 접시머리로 임의 교체하지 않는다.
- RR +L_X 방향. 명목 head top4.35, screw tip24.35. 케이블이 장착면에 끼지 않아야 한다.
사용: M2.5×20 접시머리4개 + 출력 XL 스페이서4개.

## 08. 대퇴 큰 베어링과 안쪽 종아리/큰 캡
그림: 대퇴 베어링 자리, 양쪽 Ø7 반축을 서로 향하게 배치한 폭4 단면.
- 큰 베어링7×13×4 한 개를 대퇴 끝 자리에 넣는다. 외륜을 지지하여 넣는다.
- 안쪽 종아리의 Ø7 반축과 큰 캡의 Ø7 반축을 베어링 양쪽에서 맞춘다. 작은 캡을 여기 쓰지 않는다.
- 베어링은 두 출력 반축 둘레에 위치한다. M3 나사로 금속 외륜을 직접 끌어당겨 고정하는 그림을 만들지 않는다.
- 이 단계에서는 큰 캡을 받쳐 놓고 다음 단계에서 반대판과 함께 최종 체결한다.
사용 나사: 없음.

## 09. 종아리 반대판과 TPU발 닫기
그림A: 큰 관절 M3×22 전체 축방향 스택. 그림B: 중간2곳/발1곳 M3×18 세 화살표.
- 05단계에서 푸시로드와 연결해 둔 반대판을 가져와 큰 캡 자리와 두 중간 체결부를 맞춘다. TPU발도 두 판 사이의 발끝 형상에 맞춰 끼운다. 발을 강제로 넣어 PLA판을 휘게 하지 않는다.
- 큰 관절: M3×22 원통머리1개를 **안쪽 종아리 바깥 머리 포켓 → Ø7 반축 → 큰 캡 → 반대판 → 반대판 바깥 M3너트** 방향으로 넣는다. RR +L_X, 머리 받침32.9375 → 너트 받침51.8125. 와셔 없음.
- 중간2곳과 발1곳: M3×18 원통머리3개를 **종아리 반대판의 머리 포켓 → 안쪽 종아리의 깊은 육각 너트 포켓** 방향으로 넣는다. RR -L_X, 머리 받침48.8125 → 너트 받침34.9375. 와셔 없음.
- 처음에는 모든 위치를 맞춘 뒤 균등하게 조인다. 큰 관절이 뻑뻑해지면 힘으로 조여 마무리하지 말고 반축/캡/베어링 안착을 다시 확인한다.
사용: M3×22 1개 + M3×18 3개, 이미 배치한 M3너트4개.

## 10. 크랭크를 무릎 XL 출력 혼에 연결
그림: 큰 중앙 구멍은 기존 혼 중심 나사 접근, 주변4구멍만 표시.
- 앞에서 연결된 크랭크를 무릎 XL 출력 혼에 맞춘다. 링크를 억지로 굽혀 네 구멍을 맞추지 않는다.
- M2×8 원통머리4개를 **크랭크 바깥 평면에서 혼 쪽으로** 넣는다. 너트/와셔 없음. RR -L_X, 머리 받침53.25 → 혼면48.
- XL 혼의 네 M2 나사구멍을 사용한다. 사이사이 Ø1.7 평구멍에 M2 기계나사를 억지로 넣지 않는다. 중앙 혼 고정나사는 기존 것을 유지한다.
사용: M2×8 4개.

## 11. XM과 요크를 먼저 결합
그림: XM 앞 코너4곳의 스페이서와 낮은 접시머리, 움직이는 캐리어는 아직 떨어져 표시.
- XM 케이블을 먼저 연결하고 요크/캐리어와 닿지 않게 경로를 확보한다.
- XM 앞쪽 네 파인 자리에 XM 스페이서4개를 넣고 요크를 맞춘다.
- M2.5×14 낮은90°접시머리4개를 **요크 앞쪽 접시 자리 → XM 앞쪽 케이스** 방향으로 넣는다. 너트/와셔 없음. 기존 네 코너 나사를 교체한다.
- RR -H_X, 명목 head top-4.75 → tip-18.75. 혼쪽 움직이는 캐리어를 먼저 달면 드라이버 접근이 나빠지므로 이 순서를 지킨다.
사용: M2.5×14 접시머리4개 + XM 스페이서4개.

## 12. 빈 롤 혼 캐리어를 먼저 연결 — 여기만 평와셔
그림: 나사머리 → 평와셔 → 롤 캐리어4 mm → XM 혼 단면, 네 곳 모두 확대.
- 피치 모터와 반대편 캐리어가 없는 **빈 혼 쪽 캐리어**를 XM 혼에 맞춘다. 피치 모터가 들어간 뒤에는 머리 뒤 공간이 약1.2 mm뿐이라 드라이버 접근이 막힌다.
- M2×6 원통머리4개 각각에 M2 평와셔(2.2×5×0.3 mm)1개씩 끼운다.
- **나사머리–와셔–롤 혼 캐리어–XM 혼** 순서로 체결한다. 와셔를 캐리어와 혼 사이에 넣지 않는다. 너트 없음.
- RR -H_X, 머리 아래 와셔 바깥면0.3 → 캐리어 외측0 → 혼 접촉면-4. 명목 나사 삽입1.7 mm. 와셔를 생략하면2 mm 최대깊이에 도달하므로 생략하지 않는다.
- 이 네 나사를 먼저 균등하게 마무리한 다음 피치 모터를 캐리어에 넣는다. 반대편 지지대는 아직 장착하지 않는다.
사용: M2×6 4개 + M2 평와셔4개.

## 13. 완성한 피치/다리 모듈을 롤 캐리어에 넣기
그림: 피치 모터를 두 캐리어 사이에 넣고 위4/아래4 태핑 나사를 따로 색 표시.
- 피치 모터 케이블을 먼저 연결하고 눌리지 않게 뺀다.
- 먼저 XM에 이미 연결된 혼 쪽 캐리어에 완성한 피치 모터/다리 모듈을 넣어 받친다. 이 캐리어의 M2.6×8 네 나사를 체결한다.
- 반대편 베어링 캐리어도 피치 XL에 맞추고 나머지 M2.6×8 네 나사를 체결한다. 고정 지지대는 아직 별도로 둔다. 여기에 XL 키 스페이서를 넣지 않는다.
- M2.6×8 지정 팬머리 태핑나사8개를 **캐리어 외측 → 피치 XL 플라스틱 케이스 측면** 방향으로 넣는다. 각 캐리어4개(윗면2/아랫면2), 두 캐리어 합계8개. 너트/와셔 없음.
- RR 골반 H_Z=+8.75에서 아래로4개, H_Z=-28.75에서 위로4개. 케이스면은+4.25/-24.25, 캐리어 두께4.5이다.
사용: M2.6×8 태핑8개.

## 14. 롤 베어링을 넣고 반대편 고정 지지대로 닫기
그림: 베어링 캐리어의 열린면, MR137, 고정지지대 축을 각각 분리한 세 단계.
- 반대편 베어링 캐리어 입구에 접근 가능한 상태에서 남은 큰 베어링7×13×4 한 개를 움직이는 롤 베어링 캐리어의 Ø13.15·깊이4 자리에 넣는다. 입구 쪽에서 외륜을 지지해 안쪽 어깨까지 넣는다. 캐리어 자체좌표 X=-5 쪽이 입구, -1 쪽이 어깨다.
- 앞 단계에서 XM 혼과 피치 모터/두 캐리어가 연결되어 있으므로 전체를 받친다. 고정 지지대는 아직 별도로 둔다.
- 반대쪽에서 고정 지지대 Ø7 축을 베어링 내경에 맞춰 넣고 지지대 밑부분을 요크의 두 구멍에 맞춘다. 축에 넣을 때 내륜을 지지하고 볼을 통해 압력을 전달하지 않는다.
- M2.5×8 원통머리2개를 **고정 지지대 바깥의 원형 머리 포켓 → 요크 속 미리 넣은 M2.5너트** 방향으로 넣는다. 와셔 없음. RR -H_X, 머리 받침58 → 너트 받침52.5, 나사끝50.0, 막힌벽49.5.
- 고정 지지대를 먼저 완전히 고정한 후 서로 연결된 두 캐리어 양끝을 동시에 끼우려 하지 않도록 이 순서를 제시한다. 요크 너트는02단계에서 먼저 넣어둔다.
사용: M2.5×8 2개, 이미 배치한 M2.5너트2개.

## 15. 한 다리 완성 확인
- 베어링 관절이 손으로 천천히 움직이는지, 나사끝이 닿는지, 케이블이 나사 밑이나 움직이는 틈에 끼는지 확인한다.
- 일부 M3 머리는 포켓에서1 mm, 너트는0.4 mm 나온다. 이것만 보고 더 깊이 조이거나 포켓을 억지로 누르지 않는다.
- 표시한 나사 길이/머리 형식/와셔 위치를 체크하고 이후 다른 세 다리를 조립한다.

## 네 모서리 배치 페이지
로봇 전진방향 화살표를 반드시 표시한다.
- RR 오른쪽 뒤: RR 대퇴/안쪽 종아리/반대판 + RR 요크.
- FR 오른쪽 앞: RR 대퇴/안쪽 종아리/반대판 + LR 요크.
- LR 왼쪽 뒤: LH 대퇴/안쪽 종아리/반대판 + LR 요크.
- FL 왼쪽 앞: LH 대퇴/안쪽 종아리/반대판 + RR 요크.
- 크랭크·푸시로드·캡·발·두 캐리어·고정지지대는 공용이다.
- 앞다리 피치 모터 케이스는 대응 뒷다리에 비해 출력축 둘레로180° 다른 방향이다. 무릎 모터까지 함께 뒤집는 뜻이 아니다. 앞다리 그림은 해당 최종 전체보기 모델 배치를 사용한다.
- 좌우에서 머리/너트 방향을 설명할 때 위 RR L_X 수치만 복사하지 않는다. 부품에 실제 있는 둥근 머리자리/육각 너트자리 및 선택된 모서리 모델을 기준으로 화살표를 그린다.
